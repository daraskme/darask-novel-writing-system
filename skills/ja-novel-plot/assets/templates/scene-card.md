# 場面カード
<!-- 1回の本文生成用の小場面を設計する。概ね800〜2000字を目安とし、短い繋ぎは水増ししない。
     同じ物語上の場面を複数の生成区間へ分けてもよい。時刻・場所・視点を不自然に変えず、状態を引き継ぐ。
     短い作品はこのカード1枚でもよい。short は notes.md、serial は章ビートの [[scenes]] でも同じ情報を持てる。
     追加の id / target_chars / entry_state / exit_state / handoff は任意で、従来のカードも使える。 -->

- 小場面ID（id。章内で一意の s01 等。順序を変えても維持）:
- 字数目安（target_chars。未設定なら省略）:
- 入口の状態（entry_state。所在・持ち物・知識・進行中の動作）:
- 目的（視点人物がこの場面で欲しいもの）:
- 衝突（それを阻むもの）:
- 変化（場面の前後で変わること）:
- 視点:
- 関心の錨（注意が向かう 1 つの対象）:
- 知識状態（誰が何を知り、何を知らないか）:
- 出口の状態（exit_state。次で済んだこととして扱えるもの）:
- 次への接続（handoff。次のID、渡す動作・返答・問い。終端なら閉じること）:
- 終わり方（この場面で満たすこと・残すこと）:
- 使う技法カード（必要なものだけ）:

<!-- 例（見本作『索道日誌』ch003 の場面 1）:
- 小場面ID: s01
- 字数目安: 1200
- 入口の状態: 日誌はちづるの鞄。所長は機械室で日誌を探している
- 目的: 日誌を所長に見られずに書庫へ戻す
- 衝突: 所長が先に来ていて、日誌を探している
- 変化: ちづるが嘘をつく側になる
- 視点: ちづる（三人称一元）
- 関心の錨: 所長の手の中の鍵束
- 知識状態: ちづるは筆跡が祖父のものだと確信。所長は日誌が一晩無かったことだけ知っている
- 出口の状態: 日誌は鞄のまま。ちづるは嘘をつき、所長から点検を指示された
- 次への接続: s02。指示への応答から同じ機械室で点検を始める。入室や日誌の説明を繰り返さない
- 終わり方: 所長の指示を受け、鞄の口を押さえるところで切る
- 使う技法カード: 会話 / 対決と交渉
-->
