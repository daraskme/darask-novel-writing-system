# 作者の校閲指示

校閲リーダーが作る `NNN-日時-識別子.md` を置く。1回の保存が1ファイル。

指示には対象の `main/NNN.txt`、閲覧した版のコミット、静的配信では本文SHA-256、引用、段落番号、種別が入る。作業コピーから読んだ場合はコミット未記録と表示される。

## 反映手順

1. STATUSと対象ファイルを読み、ja-novel-reviseを使う。版が違う場合は段落番号より引用を優先する。
2. 修正・増やす・減らすを依頼範囲で反映する。メモは本文の変更指示と区別する。
3. mainを直接直した差分は小場面へ戻し、結合稿と同期する。設定や数字が変わればwiki/canonとプロットも更新する。
4. 字数、前後のつながり、必要な表記と同期を検証する。
5. 元ファイル末尾へ、各指示の反映結果・例外を追記する。全件処理した指示をdone/へ移す。未処理があれば理由を記し、元の場所に残す。
6. STATUSを更新し、指示ファイル・反映結果・検証結果を説明したPRを作る。

依頼例: 「feedback/の第3話の指示を反映して、変更をPRにまとめて。」

## PR本文への指示

「対象PR」がある指示は、記載の閲覧コミット・本文ハッシュ・引用を照合し、修正先ブランチへ反映します。指示の保存先ブランチと原稿の修正先は区別してください。PR更新後の下書きは版ごとに分かれ、古い版は「PR下書きを保存」から取り出せます。
